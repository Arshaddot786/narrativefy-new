# Narrativify Website

Static, responsive website for Narrativify. Upload the contents of this folder to your GitHub repository and connect the repository to Vercel.

## Files
- `index.html`: homepage
- Service pages: social media management, managed conversational marketing, Conversation Intelligence Radar, Industry Visibility & Creator Distribution
- `pricing.html`, `faq.html`, `case-studies.html`, `about.html`, `contact.html`, `refer.html`
- `privacy.html`, `terms.html`
- `assets/style.css`, `assets/site.js`
- `sitemap.xml`, `robots.txt`, `llms.txt`

## Deployment
1. Extract the ZIP.
2. Upload the files and folders inside this directory to the root of your GitHub repository (not the ZIP itself).
3. Commit the changes.
4. In Vercel, import or connect that repository. For a plain static site, set the framework preset to Other and leave build command blank; output directory is the repository root.
5. Add `narrativify.com` and `www.narrativify.com` in Vercel Settings → Domains and follow the exact DNS records shown there.
6. Verify links, mobile layout, form email behavior and domain redirects after deployment.

## Before launch
- Confirm the contact email and any required business/contact details.
- Confirm privacy/legal wording reflects actual analytics, cookies, forms, processors and applicable laws.
- Campaign examples are sample strategies, not verified customer case studies.
- Network and capacity figures are based on Narrativify's supplied claims; maintain internal evidence and clarify campaign-specific availability.
